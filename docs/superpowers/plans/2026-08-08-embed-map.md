# Embed Google Maps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the static/clickable "Lokasi Kantor" card with a fully embedded Google Maps iframe for direct interaction.

**Architecture:** Modify the `src/pages/LandingPage.jsx` component to remove the `<a>` wrapper for the map and insert an `<iframe>` with React-compatible properties.

**Tech Stack:** React, JSX, TailwindCSS

## Global Constraints
- React JSX must be used for frontend changes, meaning properties like `allowfullscreen`, `style="border:0;"`, and `referrerpolicy` must be converted to `allowFullScreen`, `style={{ border: 0 }}`, and `referrerPolicy`.

---

### Task 1: Embed Maps Iframe

**Files:**
- Modify: `src/pages/LandingPage.jsx`

**Interfaces:**
- Consumes: User-provided Google Maps embed HTML.
- Produces: An embedded iframe displaying the location.

- [ ] **Step 1: Replace the Lokasi Kantor card content**

In `src/pages/LandingPage.jsx`, find the `div` with `className="card overflow-hidden h-80 lg:h-auto"` (around line 1003). Replace its inner contents (the `<a href={kontak.maps_url...>` element and everything inside it) with the following iframe block. Ensure `h-80 lg:h-full` or a defined height is used to prevent the map from collapsing in the flex/grid layout.

```javascript
          <div className="card overflow-hidden h-80 lg:h-full min-h-[320px]">
            <iframe 
              src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!1d3944.6387866534924!2d116.34563369999998!3d-8.6306323!2m3!1f0!2f0!3f0!3m2!1i1024!2i768!4f13.1!3m3!1m2!1s0x2dcdb51ef122a593%3A0x4144a4852454998c!2sAL%20MARWA%20TOUR%20%26%20TRAVEL!5e0!3m2!1sen!2sid!4v1786180906473!5m2!1sen!2sid" 
              className="w-full h-full" 
              style={{ border: 0 }} 
              allowFullScreen 
              loading="lazy" 
              referrerPolicy="strict-origin-when-cross-origin"
            ></iframe>
          </div>
```
